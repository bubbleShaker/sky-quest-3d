# Sky Quest 3D 〜炎竜と空の村〜

ブラウザで遊べる 3D アクション RPG です。インストール不要で、PC でもスマホでも遊べます。

**▶ プレイ: https://bubbleshaker.github.io/sky-quest-3d/**

## ストーリー
北の火口で炎竜ヴァルガスが目覚め、空の村の周りに魔物があふれ出した。
村長の頼みを受け、スライム退治 → ゴブリンに奪われた「黄金の王冠」の奪還 → 炎竜討伐 に挑もう。

## 操作方法
| 操作 | PC | スマホ |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面左側をドラッグ |
| 視点 | マウス（画面クリックでロック、Esc で解除）/ ホイールでズーム | 画面右側をドラッグ |
| 攻撃（3段コンボ） | 左クリック / J | ⚔ ボタン |
| 回避 | 右クリック / Shift / K | 回避ボタン |
| ジャンプ | Space | 跳ぶボタン |
| 回転斬り（MP10） | Q | 回転ボタン |
| 火球（MP8） | E | 火球ボタン |
| 話す・調べる | F / Enter | 話すボタン |
| ポーション / エーテル | 1 / 2 | 薬ボタン |
| メニュー | I / Tab / ☰ | ☰ |
| 音の ON/OFF | M | メニューから |

## 遊び方のヒント
- 村の中央の **泉** で休むと HP・MP が全回復し、セーブされます（30 秒ごとの自動セーブもあります）。
- 商人の店で武器・防具・回復アイテムを買えます。
- 敵が赤く点滅したら攻撃の合図。回避の転がり中は無敵です。
- 炎竜に挑むのはレベル 6〜7 以上が目安です。

## 技術
- [Three.js](https://threejs.org/) を CDN から ES Modules で読み込み、ビルド不要の静的サイトとして構成しています。
- 地形・木・キャラクターはすべてコードでプロシージャル生成しており、外部の画像やモデルは使っていません。
- 効果音と BGM は Web Audio API でその場で合成しています。

## ローカルで動かす
```sh
python3 -m http.server 8000
# http://localhost:8000/ を開く
```

```
src/camera.js     三人称カメラ
src/input.js      キーボード/マウス/タッチ入力
src/audio.js      効果音と BGM
src/save.js       セーブ/ロード
```
